# SkyCast Live Weather Dashboard 🌤️

SkyCast is a modern, responsive, and feature-rich weather dashboard web application that provides real-time meteorological data, interactive weather maps, telemetry, and detailed analytics for cities worldwide.

## ✨ Features

* **Live Weather Data:** Real-time temperature, humidity, wind speed, and atmospheric conditions fetched via live APIs.
* **Interactive Analytics & Statistics:** Dynamic weekly temperature trends visualized with custom, responsive bar graphs and statistical metrics (Max, Min, and Average temperatures).
* **Interactive Weather Map & Radar:** Regional overview layout tracking live meteorological conditions across key metropolitan areas.
* **Unit Conversion:** Seamless toggle between Celsius (°C) and Fahrenheit (°F).
* **Modern UI/UX:** Clean dark-themed dashboard built with custom CSS and modern JavaScript for smooth interactivity.

## 🛠️ Tech Stack

* **HTML5:** Semantic and structured markup layout.
* **CSS3:** Custom styling, gradients, and flexible grid/flexbox layouts.
* **JavaScript (ES6+):** Dynamic DOM manipulation, asynchronous API calls, and real-time graph rendering.
